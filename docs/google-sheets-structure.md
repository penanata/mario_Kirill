## 1. Листы (вкладки)

| Лист | Зачем |
|------|--------|
| **Заказы** | Шапка заказа: клиент, адрес, дата посадки, статус, итоги и остатки долгов. Главный экран для мобильного поставщика. |
| **Позиции** | Строки заказа со **снимком** цен на момент фиксации. |
| **Прайс** | Актуальные цена поставщика + цена продажи (~150 позиций). |
| **Платежи** | Все поступления и выплаты; куда ушли деньги; частичные оплаты. |
| **Сводка** | День поставщика + деньги (формулы / QUERY). |
| **Менеджеры** | Кто сколько продал и сколько **чистыми** (маржа) принёс. |

Почему платежи отдельно: на одном заказе бывает предоплата на р/с, а остаток — наличкой у поставщика.

## 2. Кто чем пользуется

| Роль | Заказы | Позиции | Прайс | Платежи | Сводка | Менеджеры |
|------|:------:|:-------:|:-----:|:-------:|:------:|:---------:|
| **Наталия** | ★ создаёт / правит | ★ | правка sale | ★ | день | смотрит свой срез |
| **Дарья** | ★ то же | ★ | правка sale | ★ | день | смотрит свой срез |
| **Светлана** | читает итоги | при сверке | редко | ★ сверка | ★ деньги | ★ срез по менеджерам |
| **Поставщик** | ★ день | состав | ★ цена закупа | смотрит «куда» | ★ «Мой день» | — |

Поставщик с телефона: **Заказы**, фильтр по дате посадки = сегодня.

## 3. Заголовки колонок

### Заказы

| Колонка | Смысл |
|---------|--------|
| ID заказа | `З-001`, уникальный |
| Дата создания | когда завели |
| Дата посадки | доставка + посадка |
| Клиент | ФИО / имя |
| Телефон | для звонка |
| Адрес | куда везти |
| Источник | Avito / сайт / другое |
| Менеджер | Наталия / Дарья |
| Статус | черновик / подтверждён / выполнен / отменён |
| Сумма клиенту | `=SUMIF(Позиции!B:B;A2;Позиции!H:H)` |
| Сумма поставщику | `=SUMIF(Позиции!B:B;A2;Позиции!G:G)` |
| Маржа | `=J2-K2` |
| Оплачено клиентом | `=SUMIFS(Платежи!E:E;Платежи!B:B;A2;Платежи!D:D;"от клиента")` |
| Выплачено поставщику | `=SUMIFS(Платежи!E:E;Платежи!B:B;A2;Платежи!D:D;"поставщику")` |
| Долг клиента | `=J2-M2` |
| Долг поставщику | `=K2-N2` |
| Основной канал оплаты | наличка у поставщика / на р/с / смешанно |
| Комментарий | ТК, предоплата, нюансы |

### Позиции

| Колонка | Смысл |
|---------|--------|
| ID позиции | `П-001` |
| ID заказа | ссылка на Заказы |
| Растение | как в прайсе |
| Кол-во | число |
| Цена поставщика (снимок) | из Прайс при добавлении |
| Цена продажи (снимок) | то же |
| Сумма поставщику | `=D2*E2` |
| Сумма клиенту | `=D2*F2` |
| Маржа строки | `=H2-G2` |
| Примечание | размер, сорт |

**Правило снимка:** после «подтверждён» цены в строке не трогать.

### Прайс

| Колонка | Смысл |
|---------|--------|
| ID | `R-001` |
| Название | растение |
| Ед. | шт / упак |
| Цена поставщика | актуальная закупка |
| Цена продажи | клиенту |
| Маржа ед. | `=E2-D2` |
| Активен | да / нет |
| Дата обновления | когда меняли |
| Кто обновил | поставщик / менеджер |
| Примечание | |

### Платежи

| Колонка | Смысл |
|---------|--------|
| ID платежа | `ОПЛ-001` |
| ID заказа | на какой заказ |
| Дата | когда деньги прошли |
| Тип | от клиента / поставщику |
| Сумма | ₽ |
| Куда / откуда | **наличка у поставщика** / **на р/с** |
| Кто зафиксировал | имя |
| Комментарий | предоплата, СДЭК |

**Частичные оплаты:** несколько строк с одним ID заказа.

### Менеджеры

| Колонка | Смысл |
|---------|--------|
| Менеджер | Наталия / Дарья (имя как в Заказы!H) |
| Период с | опционально — дата посадки от |
| Период по | опционально — дата посадки до |
| Продажи (сумма клиенту) | SUMIFS по Заказы!J, менеджер, статус ≠ отменён (+ период) |
| Закуп поставщику | SUMIFS по Заказы!K |
| Чистыми (маржа) | Продажи − Закуп |
| Число заказов | COUNTIFS по менеджеру |

Если **Период с/по** пустые — считаются все даты. Иначе фильтр по **дате посадки**.

Пример (строка 2, локаль RU с `;`):

```
=IF(AND(B2="";C2="");
  SUMIFS(Заказы!J:J;Заказы!H:H;A2;Заказы!I:I;"<>отменён");
  SUMIFS(Заказы!J:J;Заказы!H:H;A2;Заказы!I:I;"<>отменён";Заказы!C:C;">="&B2;Заказы!C:C;"<="&C2))
```

Чистыми: `=D2-E2`. Число заказов — аналогично через `COUNTIFS`.

В `.xlsx` формулы уже проставлены на английском синтаксисе (запятые) — Google Sheets их подхватывает после открытия.

### Сводка

**Блок «День поставщика»** (дата в `B2`):

```
=QUERY(Заказы!A:R;
"select A,C,D,E,F,J,K,Q where C = date '"&TEXT(B2;"yyyy-mm-dd")&"' and I <> 'отменён' order by F";1)
```

**Деньги:**

| Показатель | Формула |
|------------|---------|
| Выручка (выполненные) | `=SUMIF(Заказы!I:I;"выполнен";Заказы!J:J)` |
| Закуп (выполненные) | `=SUMIF(Заказы!I:I;"выполнен";Заказы!K:K)` |
| Маржа | выручка − закуп |
| Долг клиентов | `=SUMIF(Заказы!I:I;"<>отменён";Заказы!O:O)` |
| Долг поставщику | `=SUMIF(Заказы!I:I;"<>отменён";Заказы!P:P)` |
| Наличка / р/с | `SUMIF` по Платежи!F |

## 4. Ключевые формулы (кратко)

| Что | Где | Как |
|-----|-----|-----|
| Сумма клиенту по заказу | Заказы!J | SUMIF по Позиции!H |
| Сумма поставщику | Заказы!K | SUMIF по Позиции!G |
| Маржа заказа | Заказы!L | J − K |
| Оплачено / выплачено | Заказы!M/N | SUMIFS Платежи |
| Долг клиента / поставщику | Заказы!O/P | J−M / K−N |
| Куда деньги | Платежи!F | наличка / р/с |
| Продажи менеджера | Менеджеры!D | SUMIFS Заказы |
| Чистыми менеджера | Менеджеры!F | D − E |

---

## 5. Как учитывать оплату

1. В **Платежи** — новая строка.
2. Тип: `от клиента` / `поставщику`.
3. Куда: `наличка у поставщика` / `на р/с`.
4. Частично — несколько строк; остаток в Долг клиента / Долг поставщику.
5. Смешанный заказ: Заказы!Q = `смешанно`, детали в Платежи.

---

## 6. Ежедневный workflow (7 шагов)

1. Правка **Прайс** при смене цены (дата + кто).
2. Новый заказ в **Заказы** (`черновик`) + строки в **Позиции** со снимком.
3. Согласовали → **подтверждён** (снимки не менять).
4. Деньги → **Платежи**.
5. Утро: поставщик — фильтр по дате на **Заказы** / **Сводка**.
6. После посадки → **выполнен**; Светлана сверяет долги.
7. Раз в неделю / месяц: **Менеджеры** — кто сколько чистыми (при необходимости задать период).

---

## 7. Проверки данных и цвета (минимум)

- Статус: `черновик`, `подтверждён`, `выполнен`, `отменён`
- Куда: `наличка у поставщика`, `на р/с`
- Тип платежа: `от клиента`, `поставщику`
- Канал: `наличка у поставщика`, `на р/с`, `смешанно`
- Цвет статуса: серый / голубой / зелёный / красный
- Долг > 0 → жёлтый

В `.xlsx` validation и цвета статусов уже заданы на листе Заказы.
