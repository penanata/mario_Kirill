# Каталог из Telegram-чата поставщика

Поставщик кидает в чат фото сорта и текст (цена, наличие). Google-таблица для этого плохо подходит: **фото оттуда не скачать**.

Этот каталог собирает сообщения в карточки:

- фото в исходном качестве, скачиваются по одному, пачкой по сорту или всем архивом
- цена и наличие на карточке
- поиск по названию сорта
- повторные сообщения по тому же сорту обновляют цену и остаток, а не плодят дубли

Игра «Марио» по-прежнему открывается по адресу `/mario`.

## Как запустить

Нужен Python 3.11+ или Docker.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 -m app
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Первый запуск покажет демо-сорта, чтобы было видно, как выглядит каталог.

Через Docker:

```bash
docker compose up --build
```

## Как наполнить своими товарами

### Вариант 1. Выгрузка чата (история уже есть)

1. Telegram Desktop → чат поставщика → меню ⋮ → **Export chat history**.
2. Формат **JSON**, галочка **Photos**.
3. Папку экспорта сожмите в zip.
4. На сайте откройте **Загрузить из Telegram** и отправьте zip.

Подписи разберутся автоматически: строки вроде `Сорт: …`, `Цена: 95 руб`, `Наличие: 200 шт`, `нет в наличии`, цены по высоте `60см 90р`.

### Вариант 2. Живой бот (новые сообщения сами падают в каталог)

1. @BotFather → `/newbot` → скопируйте токен в `.env` как `TELEGRAM_BOT_TOKEN`.
2. @BotFather → `/setprivacy` → **Disable** (иначе в группе бот не видит чужие сообщения).
3. Добавьте бота в чат поставщика.
4. Напишите боту `/chatid` и при желании пропишите id в `TELEGRAM_CHAT_ID`.
5. Оставьте каталог запущенным.

## Скачивание фото

- с карточки сорта — каждое фото отдельно
- **Все фото** — zip одного сорта
- **Скачать фото архивом** на главной — zip текущего фильтра; внутри папки по сортам и `info.txt` с ценой и наличием

Данные хранятся локально в папке `data/` (база SQLite и файлы фото). В git они не попадают.

Если каталог должен быть закрыт паролем, задайте `CATALOG_PASSWORD` в `.env`.
