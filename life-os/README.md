# Life OS

Персональное приложение для одного человека: день, календарь, цели, задачи, привычки, идеи, рефлексия и ассистент. Интерфейс на русском. Время по умолчанию — Asia/Bangkok, московские встречи показываются местным временем.

Это не макет. Задачи, события, цели, привычки и рефлексии пишутся в SQLite и остаются после перезапуска.

## Что работает

- Главный экран: три фокуса дня с причиной, календарь дня, цели месяца, неделя, глобальные цели, банк идей, свободное время и отметка энергии.
- Задачи: создание, выполнение, отмена, связь с целью. Одинаковая открытая задача второй раз не создаётся.
- Цели по цепочке: сфера → глобальная цель → год → квартал → месяц → неделя → задачи. Названия меняете вы.
- Календарь: день, неделя, месяц. События сохраняются локально. На компьютере их можно перетаскивать между часами, на телефоне — выбрать час в списке.
- Привычка «15 тренировок в месяц»: выполнено, пропуск, перенос. Пропуск не уменьшает цель. Новое расписание показывается до сохранения.
- После трёх переносов задача больше не двигается молча: нужно выбрать перенос, сокращение, делегирование или отмену.
- Банк идей со статусами. Примерные идеи не ваши, пока не нажмёте «Это моё». Фраза про идею не создаёт задачу.
- Рефлексия дня, недели, месяца, квартала и года. Саммари состоит из ваших ответов. Есть поиск и сравнение.
- Ассистент с любой страницы. Он предлагает изменения и ждёт «Подтвердить», «Изменить» или «Отменить».
- Голос: кнопка микрофона через распознавание браузера (`ru-RU`), если оно есть. На части iPhone его нет — тогда остаётся текст.
- Демоданные помечены и удаляются в настройках.
- PWA: можно поставить на экран «Домой».

## Что требует настройки

- **OpenAI.** Без `OPENAI_API_KEY` приложение и локальный разбор фраз работают. Облачная модель и серверная расшифровка голоса — нет. Ключ только на сервере.
- **iCloud Calendar.** Статус «требует подключения», пока не введены Apple ID и пароль приложения (не основной пароль Apple). После подключения работает импорт и отправка изменений в выбранный календарь через CalDAV. Если iCloud недоступен, локальный календарь остаётся.
- **Файл .ics** в настройках — это ручной импорт в Apple Calendar, не автоматическая синхронизация.
- **Напоминания** видны только внутри открытого приложения. Push не обещается: его нет.
- **Поиск мероприятий** по площадкам не подключён. Можно добавить карточку руками или разобрать публичную ссылку. В календарь событие попадает только после подтверждения и это не регистрация.
- **Вход.** Локально пароль не нужен. Для публикации задайте `LIFEOS_ACCESS_PASSWORD`.

## Запуск

```bash
cd life-os
cp .env.example .env.local
npm install
npm run dev
```

Откройте http://localhost:3000

База: `life-os/data/life-os.sqlite`. Секрет шифрования пароля iCloud, если не задан `LIFEOS_SECRET`, создаётся в `life-os/data/secret.key`. Эти файлы не коммитятся.

Проверка:

```bash
npm test
npm run build
```

## iPhone

1. Запустите сервер так, чтобы телефон его видел: `npm run dev -- --hostname 0.0.0.0`.
2. В Safari на iPhone откройте `http://<адрес-компьютера>:3000`.
3. «Поделиться» → «На экран Домой».

Полноценный service worker на iPhone требует HTTPS. В локальной сети иконка на домашнем экране открывает сайт, но офлайн-режим ограничен: данные живут на сервере, не в телефоне.

Для постоянного адреса поднимите Node-сервер с HTTPS и диском, где лежит `data/`. SQLite на serverless-хостинге без диска сотрётся.

```bash
docker build -t life-os .
docker run --env-file .env.local -p 3000:3000 -v life-os-data:/app/data life-os
```

Переменные: `OPENAI_API_KEY`, `OPENAI_MODEL`, `LIFEOS_ACCESS_PASSWORD`, `LIFEOS_SECRET`, `LIFEOS_TZ`.
