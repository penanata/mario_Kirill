# Слова

Карточки английских слов для телефона. Список хранится только в браузере на этом устройстве.

При первом открытии уже есть слова от преподавателя. Свои слова можно добавить дальше — они не стираются.

На ноутбуке список и карточка стоят рядом. Пробел или Enter переворачивает карточку, стрелка влево — «Ещё раз», вправо — «Знаю».

## Как открыть на телефоне

1. Откройте файл `index.html` в браузере.
2. Или добавьте страницу на экран «Домой»: в меню браузера выберите «На экран Домой» (Add to Home Screen) и запускайте иконку «Слова».

После «На экран Домой» приложение открывается и без интернета.
