# Слова

Карточки английских слов для телефона. Список хранится только в браузере на этом устройстве.

При первом открытии уже есть слова от преподавателя. Свои слова можно добавить дальше — они не стираются.

Сначала открывается одна карточка. Список, добавление и правка — по кнопке «Список». «К карточке» возвращает обратно.

Пробел или Enter переворачивает карточку, стрелка влево — «Ещё раз», вправо — «Знаю». Пока курсор в поле ввода, эти клавиши ничего не переворачивают.

Быстрое «Знаю» (меньше 8 секунд) показывает слово ещё один раз и отпускает. «Ещё раз» или долгое «Знаю» возвращает слово раньше и чаще. Это запоминается на устройстве.

## Как открыть

Страница: https://penanata.github.io/mario_Kirill/vocab-trainer/

На телефоне добавьте её на экран «Домой»: в меню браузера выберите «На экран Домой» (Add to Home Screen) и запускайте иконку «Слова». Файл `index.html` по-прежнему можно открыть с компьютера.

После «На экран Домой» приложение открывается и без интернета.
